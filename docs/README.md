# MCO-1D Documentation Architecture

The documentation in this repository is organized into three tiers. All physical constants in active documentation must match [`../config/airframe_spec.json`](../config/airframe_spec.json) and [`../bom/bom.csv`](../bom/bom.csv).

## 1. MCO-1D Mark 1 Authoritative Suite (`docs/mark1/`)
**[PRIMARY AUTHORITATIVE BASELINE]**
All physical manufacturing, component sourcing, electronics commissioning, flight test execution, and piloting instructions live in `docs/mark1/`:
- [`MCO-1D_Mark1_Master_Specification.md`](mark1/MCO-1D_Mark1_Master_Specification.md) — Master aerodynamic, kinematic, and power specification (`3.642 kg` installed BOM mass, `2.20 m` span, `0.28 m` chord, `2.24 m²` area, `10.0:1` capstan reduction).
- [`MCO-1D_Mark1_Bill_of_Materials.md`](mark1/MCO-1D_Mark1_Bill_of_Materials.md) — Live 39-component BOM (`$3,757.58 USD`, `3,642 g` installed airframe mass, `6,150 g` total procurement mass with spares), generated by [`../scripts/mco_bom_tool.py`](../scripts/mco_bom_tool.py).
- [`MCO-1D_Mark1_Builder_Calibration_Sheet.pdf`](mark1/MCO-1D_Mark1_Builder_Calibration_Sheet.pdf) ([`Markdown`](mark1/MCO-1D_Mark1_Builder_Calibration_Sheet.md)) — Post-build hardware handoff manifest (`FIG-01` to `FIG-08`), as-built gross weight calibration gate, and pre-flight signoff checklist.
- [`MCO-1D_Mark1_Flight_Envelope_Specification.md`](mark1/MCO-1D_Mark1_Flight_Envelope_Specification.md) — Flight operating corridors, $V$-$n$ diagram (`[-1.0g, +2.2g]` structural limits), dynamic stall scaling, and service ceilings.
- [`MCO-1D_Mark1_Manufacturing_Guide.md`](mark1/MCO-1D_Mark1_Manufacturing_Guide.md) — Additive rib print run, CF machining, spar layup, battery tray mount, and `180 N` Dyneema rigging.
- [`MCO-1D_Mark1_Commissioning_Manual.md`](mark1/MCO-1D_Mark1_Commissioning_Manual.md) — Hardware assembly, 8x ODrive CAN configuration (`GoolRC 5010-14 360KV`), 16x AGFRC servo calibration, and ADC zeroing.
- [`MCO-1D_Mark1_Operator_Manual.md`](mark1/MCO-1D_Mark1_Operator_Manual.md) — Pilot Operating Handbook (POH), Unified Wave Lever zones, WIG floor governor, and emergency checklists.
- [`MCO-1D_Mark1_Flight_Test_Protocol.md`](mark1/MCO-1D_Mark1_Flight_Test_Protocol.md) — 4-phase test cards: TC-01 (Bench), TC-02 (Tethered lift), TC-03 (Truck sweep), TC-04 (First free flight STOL).
- [`MCO-1D_Mark1_Test_Card_Worksheets.md`](mark1/MCO-1D_Mark1_Test_Card_Worksheets.md) — Field data acquisition worksheets and printable PDF binder in [`mark1/worksheets/`](mark1/worksheets/).
- [`MCO-1D_Mark1_Software_Reference.md`](mark1/MCO-1D_Mark1_Software_Reference.md) — Real-time 50 Hz executive loop, safety governors, and CAN frame dictionary.
- [`MCO-1D_Fasteners_and_Inserts_Mass_Budget.md`](mark1/MCO-1D_Fasteners_and_Inserts_Mass_Budget.md) — Fastener, bearing, dead-axle, and heat-set insert mass ledger.
- [`MCO-1D_Hierarchical_Exploded_Installation_Guide.pdf`](mark1/MCO-1D_Hierarchical_Exploded_Installation_Guide.pdf) — 2-page hierarchical installation manual (Bevel Wrist -> Stagecoach Shoulder -> Fuselage Collar).
- [`MCO-1D_V10_Powertrain_Mount_Installation_Guide.pdf`](mark1/MCO-1D_V10_Powertrain_Mount_Installation_Guide.pdf) — V10 Powertrain Stand, Dual-Shear Top Brace, and ODrive Micro mounting guide.
- [`MCO-1D_V10_Stagecoach_Wrist_Assembly_Guide.pdf`](mark1/MCO-1D_V10_Stagecoach_Wrist_Assembly_Guide.pdf) — V10 7-spoke Stagecoach sector drum and bevel differential wrist guide.
- [`MCO-1D_Electronics_and_Systems_Guide.pdf`](mark1/MCO-1D_Electronics_and_Systems_Guide.pdf) — Avionics, CAN bus topology, and dual-SBEC 7.4V servo power distribution guide.
